# Project Roadmap & Governance

## Phase Roadmap

- **Phase 1 (CURRENT)**: Clean development foundation, FastAPI health endpoints, SQLAlchemy 2.x, Alembic, Docker PostgreSQL with pgvector, Flutter mobile structure.
- **Phase 2 (PLANNED)**: Authentication, User Profiles, Courses & Syllabus schemas, Agent orchestration interfaces.
- **Phase 3 (PLANNED)**: Memory Manager, RAG retrieval engine with pgvector, Planner agent integration.
- **Phase 4 (PLANNED)**: Push notifications, Canvas/Blackboard integrations, Advanced analytics.
